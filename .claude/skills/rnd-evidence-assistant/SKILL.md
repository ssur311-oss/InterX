# AI 기능 스킬

> AI는 **말을 해석하고 문장을 쓰는 일만** 한다.
> 날짜 비교, 금액 계산, 상태 판정, 저장, 발송은 하지 않는다. (`RULE.md` 0번 대원칙)

---

## 작업 1. 슬랙 메시지 분류 + 정보 추출 (F6)

**입력**: 메시지 원문, 보낸 사람 이름, 오늘 날짜(Asia/Seoul), 보낸 사람의 미제출·예정 증빙 목록(집행 건 요약, 증빙 종류)

**분류**
| 태그 | 의미 | 예시 |
|---|---|---|
| `delay` | 제출이 늦어진다 / 언제 내겠다 | "업체 발행이 늦어서 다음 주 화요일에 낼게요" |
| `submitted` | 냈다 / 올렸다 | "회의록 방금 드라이브에 올렸어요" |
| `question` | 서류·절차 문의 | "출장보고서 양식 어디 있어요?" |
| `budget` | 예산·잔액 문의 | "재료비 얼마 남았어요?" |
| `other` | 그 외 | 인사, 잡담 |

**출력 (JSON만)**
```json
{
  "type": "delay",
  "doc_types": ["세금계산서"],
  "planned_date": "2026-11-03",
  "reason": "거래처 세금계산서 발행 지연",
  "candidate_expense_hint": "센서 부품 구매",
  "confidence": "high",
  "needs_admin_check": false,
  "summary": "세금계산서를 11/3에 제출하겠다고 함 (거래처 발행 지연)"
}
```

**규칙**
- "다음 주 화요일", "이번 달 말" 같은 표현은 오늘 기준 `YYYY-MM-DD`로 바꾼다. 해석이 두 가지 이상이면 `null` + `needs_admin_check: true`.
- 메시지에 없는 정보는 **추측하지 말고 `null`.**
- 어느 집행 건인지는 힌트만 준다. **연결은 관리자가 한다.**
- 사내 마감일을 넘는지는 판단하지 않는다. (코드가 계산)

## 작업 2. 통보 / 재통보 문장 (F7)

**입력**: 받는 사람 이름, 과제명, 대상 증빙 목록(집행일, 내용, 증빙 종류, 상태, 예정일), 사내 마감일, 남은 일수(코드 계산값), 회차(첫 통보 / 재통보 n회), 담당자 이름

**규칙**
- 4~6문장. 한 사람의 여러 건을 **한 메시지로 묶는다.**
- **무엇이 / 왜(정산 마감) / 언제까지**를 반드시 쓴다. 숫자와 날짜는 **받은 값 그대로.**
- 첫 통보: 안내 톤. 재통보: 남은 일수를 언급하되 **질책하지 않는다.**
- 약속일 경과 건: "말씀 주신 날짜가 지나 한 번 더 확인드린다"는 식으로, 약속을 상기시키는 톤.
- 마지막 줄: 어려우면 예상 일정만 알려달라는 안내.

**예시 — 첫 통보**
> 안녕하세요 홍길동님, 사업비 담당 ○○○입니다.
> 「자율제조 AI 플랫폼」 과제의 10월 집행 건 중 아래 증빙이 아직 등록되지 않아 안내드립니다.
> • 10/14 센서 부품 구매 — 세금계산서, 검수조서
> • 10/21 기술 회의 — 회의록
> 월 정산 마감을 위해 **10/27(월)까지** 제출 부탁드립니다. 일정이 어려우시면 예상 날짜만 알려주셔도 됩니다.

**예시 — 약속일 경과 재통보**
> 홍길동님, 지난번 11/3까지 주신다고 하셨던 센서 부품 세금계산서 건 한 번 더 확인드립니다.
> 사내 마감까지 **2일** 남아 있어서요. 거래처 발행이 아직이라면 거래처 담당자 연락처를 알려주시면 제가 직접 요청드려도 괜찮습니다.

## 작업 3. 연구책임자 주간 요약 (F11, 여유 시)

**입력**: 연구책임자 이름, 과제명, 참여연구원별 미제출·약속일 경과 건수(코드 집계값)

**규칙**: 개인을 지목해 탓하지 않는다. "팀 현황 공유"의 톤. 3~4문장 + 간단한 목록.

> 김책임님, 「제조 LLM 실증」 과제 이번 주 증빙 현황 공유드립니다.
> 미제출 4건(약속일 경과 1건)이 남아 있습니다. • 이연구 2건 • 박연구 2건
> 사내 마감은 10/27(월)입니다. 팀 내에서 한 번 챙겨주시면 감사하겠습니다.

---

## 작업 4. 월 마감 보고 (F12, 여유 시)

**입력**: 과제별 집행 건수, 증빙 제출률, 위험 건과 소명 현황, 마감 넘긴 건 목록 (모두 코드 집계값)

**규칙**: 결론 먼저 한 줄 → 과제별 3줄 이내 → 남은 이슈와 다음 달 조치. 숫자는 받은 값 그대로.

---

## 하지 않는 것

- 저장, 상태 변경, 슬랙 발송을 직접 실행하지 않는다.
- 날짜 비교, 금액·일수 계산, 위험 판정을 스스로 하지 않는다.
- 지침에 없는 규정을 지어내지 않는다. 모르면 "지침 확인이 필요합니다."
- 급여·4대보험·개인정보 질문에는 "이 도구는 사업비 증빙 전용입니다"라고만 답한다.
